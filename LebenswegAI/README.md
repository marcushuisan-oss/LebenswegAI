# Lebensweg AI Android starter

Futuristic black/red Compose UI prototype for Android.


## What is included
- Android Studio project using Kotlin + Jetpack Compose
- Black/red HUD-inspired visual style
- Chat interface with local demo responses
- Input and send button
- Mic button placeholder

## Not connected yet
- Real AI provider/API
- Speech recognition and text-to-speech
- Persistent chat history

## Build
Open this folder in Android Studio, let Gradle sync, then select Build > Build APK(s).
A recent Android Studio installation, Android SDK 35, and internet access for Gradle dependencies are needed.
